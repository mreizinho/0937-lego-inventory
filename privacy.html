Política de Privacidade

Última actualização: 25 de Agosto de 2026

Esta política explica como a aplicação Inventário LEGO 0937 utiliza dados pessoais e permissões Google para gerir o inventário partilhado da Comunidade 0937.

Dados utilizados

  • Endereço de email da conta Google usada para iniciar sessão.
  • Dados de inventário introduzidos pelo utilizador, incluindo movimentos, quantidades, localizações, origem ou destino e observações.
  • Dados de catálogo e inventário existentes no spreadsheet Google configurado para esta aplicação.

Finalidades

O email é utilizado para autenticar o utilizador, confirmar o acesso ao spreadsheet e identificar o autor de cada movimento. Os restantes dados são utilizados exclusivamente para consultar e manter o inventário LEGO partilhado.

Permissões Google

A aplicação pede acesso ao Google Sheets para ler o catálogo e o stock e para registar movimentos no spreadsheet configurado. Embora a autorização Google descreva acesso a spreadsheets, o código da aplicação utiliza apenas o identificador do spreadsheet do Inventário LEGO 0937.

A permissão de ligação a serviços externos é utilizada pela função de actualização do catálogo. Esta função obtém o ficheiro de exportação de sets disponibilizado pelo Brickset e actualiza a folha BricksetSets.

Leitor de códigos de barras

Quando o utilizador activa o scanner, a câmara é processada localmente no dispositivo para reconhecer o código de barras. A aplicação utiliza apenas o valor do código detectado; não guarda nem envia fotografias ou vídeo da câmara.

Armazenamento e partilha

Os movimentos ficam guardados no spreadsheet partilhado e podem ser consultados pelas pessoas que tenham acesso a esse ficheiro. A aplicação não vende dados pessoais nem os utiliza para publicidade.

O token de acesso Google é guardado apenas no armazenamento de sessão do browser e é removido ao terminar a sessão. Não é enviado para servidores próprios da aplicação.

Serviços utilizados

A aplicação utiliza Google Identity Services, Google Sheets API e Google Apps Script API. O site é alojado no GitHub Pages e a actualização do catálogo consulta o serviço Brickset.

Conservação e direitos

Os registos do inventário são conservados enquanto forem necessários para manter o histórico de movimentos. Para pedir acesso, correcção ou eliminação de dados pessoais, contacta o responsável pela aplicação através do endereço abaixo.

Contacto
